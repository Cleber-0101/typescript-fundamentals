# 🔷 Fundamentos de TypeScript

Estudo do TypeScript como superset do JavaScript, com teoria e desafios resolvidos.

- `Fundamentos/`: tipos primitivos, arrays, narrowing
- `conceitos/`: tipagem de retorno de funções
- `Desafios/`: 5 desafios com enunciado e resolução: tipos primitivos, `any` × `unknown`, funções, interfaces/type alias/union/literal, narrowing e assertions

```bash
npx tsc && node Fundamentos/arrays.js
```
